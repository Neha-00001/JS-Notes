# Array Methods — Quick Revision

`forEach()` → perform an action for every element; does not create a new array.

`map()` → transform every element → returns a new array.

`filter()` → keep elements that satisfy a condition → returns a new array.

`find()` → returns the first element that satisfies a condition; if none → `undefined`.

`some()` → checks if at least one element satisfies condition → `true/false`.

`every()` → checks if all elements satisfy condition → `true/false`.

`includes()` → checks if an exact value exists → `true/false`.

`reduce()` → combines array elements into one final value.

### ⭐ Common patterns

`filter().map()` → select data → transform data

`reduce()` → calculate total / combine data

### Other methods to recognize

`sort()` → sorts elements
`reverse()` → reverses array
`slice()` → extracts/copies part without changing original
`splice()` → adds/removes elements and changes original
